# What if the bill has already been sent?

This needs stricter rules.

Suppose:

```text
October Bill
Total = ₹13,220
Status = PENDING
```

Owner discovers another ₹300 water charge.

**Don&#39;t silently modify the bill after the tenant has been notified.**

Instead provide:

### Option A — Edit before payment

Allow:

```text
Edit Bill
```

and show:

&gt; This will change the amount payable to the tenant.

Then update the bill and notify the tenant again.

### Option B — Add adjustment

If the bill is already paid or finalized:

```text
October Bill
Original Total: ₹13,220
```

Don&#39;t modify the original historical transaction.

Create:

```text
Adjustment
Water Charge
₹300
```

and carry it to the next bill.

For example:

```text
November Bill

November Rent        ₹12,000
Maintenance             ₹500
Previous Adjustment     ₹300
-----------------------------
Total                 ₹12,800
```

This is much safer for financial records.

# The key database protection

You absolutely need a **unique constraint**.

Something like:

```text
tenantId + billingMonth
```

must be unique.

Conceptually:

```js
{
    tenantId: ObjectId,
    billingMonth: &quot;2026-10&quot;
}
```

with:

```text
UNIQUE(tenantId, billingMonth)
```

So even if:

* cron runs twice
* server restarts
* owner presses Generate
* background job retries
* API is called twice

you cannot accidentally create:

```text
October Bill #1
October Bill #2
```

for the same tenant.

# One more important distinction

Don&#39;t let the **old rent record** and **new MonthlyBill** both behave as payable invoices.

Instead:

### MonthlyBill = what tenant owes

```text
MonthlyBill
 ├── Rent
 ├── Electricity
 ├── Water
 ├── Maintenance
 └── Other
```

### PaymentTransaction = money received

```text
PaymentTransaction
 ├── billId
 ├── amount
 ├── method
 ├── transactionReference
 └── paidAt
```

Your existing rent/billing data can remain for **historical compatibility**, but going forward the new `MonthlyBill` should become the financial document that the tenant actually pays.
